## 2. Evidence Against Key Professor / Defense Inquiries

### Question 1: "Show me exactly where the live data enters."
* **Evidence:**
  * When an intern takes a quiz in the Streamlit UI, [`app/app.py`](file:///C:/Users/raghu/Downloads/SkillTrack-ML/SkillTrack-ML/app/app.py#L273) executes `save_mcq_attempt()`.
  * The raw score, questions, and timestamp are inserted into table `mcq_attempts`.
  * In the demo, quiz score `95.0` was submitted for intern `10001` at `2026-10-08T07:19:16`.

### Question 2: "Show me where it enters the ML dataset."
* **Evidence:**
  * Immediately within `save_mcq_attempt()`, line 297 calls `src/data/live_data_ingestion.py::ingest_observation()`.
  * This generates observation row **`OBS-31`** in table `ml_observations`.
  * Provenance: `source = 'quiz'`, `event_type = 'mcq_attempted'`, `label_status = 'IMMEDIATE_LABELED'`, `training_eligible = 1`.
  * The performance state is simultaneously synchronized to `intern_performance` via `_sync_observation_to_performance()`.

### Question 3: "Show me which features changed."
* **Evidence:**
  * Comparing feature vector snapshots between Trace #3 and Trace #4 reveals deterministic mathematical changes:
    * `mcq_attempts`: $8 \to 9$ ($+1$)
    * `mcq_score`: $89.18 \to 91.51$ ($+2.33$)
    * `skill_score`: $88.44 \to 89.41$ ($+0.97$)
    * `final_performance_score`: $87.75 \to 88.66$ ($+0.91$)
    * `historical_mcq_score_avg`: $84.269 \to 84.502$ ($+0.233$)
    * `historical_skill_score_avg`: $81.964 \to 82.061$ ($+0.097$)
  * All 37 other features (coding scores, project hours, demographics) remained strictly invariant.

### Question 4: "Show me which prediction used it."
* **Evidence:**
  * Persistent table `prediction_traces` contains `trace_id = 4`.
  * `trace_id = 4` records:
    * `data_cutoff_timestamp = '2026-10-08T07:19:16'`
    * `latest_observation_id = 'OBS-31'`
    * `observation_ids_used = [..., 31]`
    * `predicted_performance = 88.9`
  * In contrast, `trace_id = 3` (recorded prior to the quiz) had `data_cutoff_timestamp = '2026-10-08T07:19:15'` and did not contain `OBS-31`.

### Question 5: "Show me the model that made that prediction."
* **Evidence:**
  * The production forecast is generated by:
    * `gap_model`: Balanced Logistic Regression
    * `perf_model`: Ridge Regression
  * Registered version: `v_20261007_125928`
  * Artifact path: `models/production_model.pkl`
  * Prediction source: `production_pipeline`

### Question 6: "Show me whether the online learner learned from it."
* **Evidence:**
  * Because `mcq_attempted` has an immediate outcome (`95.0`), it meets the criterion for immediate incremental supervised learning.
  * `src/ml/online_learner.py::OnlineEventLearner.update_with_event()` executed `self.model.partial_fit()`.
  * Registered in table `online_learning_updates`:
    * `update_id = 11`
    * `observation_ids = 'OBS-31'`
    * `model_version_before = 'online_sgd_v45'`
    * `model_version_after = 'online_sgd_v46'`
    * `step_loss = 1484.5276`
  * The online learner runs in **Shadow / Experimental Mode** so incremental event drift does not destabilize the production batch Ridge baseline without controlled promotion.

### Question 7: "Show me that future data was not leaked."
* **Evidence:**
  * Strict temporal cutoffs are enforced in `src/ml/predict.py::build_feature_vector()` using `data_cutoff_timestamp`.
  * Queries filter: `WHERE intern_id = ? AND timestamp <= cutoff_timestamp`.
  * In test `tests/test_prediction_lineage.py::test_temporal_causality_prediction_before_and_after_event`:
    * A prediction at $T_0$ was generated.
    * An event was ingested at $T_1$.
    * The $T_0$ prediction was re-verified and strictly excluded the $T_1$ event.
    * A prediction at $T_2$ was generated and included the $T_1$ event.
  * Verified passing across automated unit tests.
